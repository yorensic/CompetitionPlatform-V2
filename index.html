三条可复用的准备路线。

01

蓝桥杯全国软件大赛

所需基础：掌握 C/C++ 或 Java 基础，了解基础数据结构。

准备周期：提前 3 个月刷真题。

书与课：《算法竞赛入门经典》 / B站真题精讲。

踩坑经验：不要盲目刷难题，基础题必须保证正确率。

02

中国国际大学生创新大赛（互联网+）

所需基础：具备一定的产品思维、PPT 制作能力，以及核心技术支持。

准备周期：提前半年组队，进行项目孵化。

书与课：《精益创业》 / 中国大学MOOC《创新创业基础》。

踩坑经验：商业计划书不能太空，一定要有实际落地数据，不能纯 PPT 创业。

03

全国大学生数学建模竞赛

所需基础：掌握一门编程语言（MATLAB/Python），熟悉一种排版工具（LaTeX/Word）。

准备周期：暑假期间进行为期 1-2 个月的集训。

书与课：《数学建模算法与应用》 / 推荐B站各类数模国奖经验分享。

踩坑经验：不要执着于完美模型，摘要写得好不好直接决定能不能拿国奖。
